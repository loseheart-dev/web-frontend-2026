# 个人博客创作与阅读平台：立项报告

## 一句话介绍

为需要持续整理学习与生活记录的个人创作者提供浏览器端博客创作、分类归档与阅读互动的平台；作者在本机完成内容管理，访客可浏览、检索并留下轻量反馈。

## 内容主题

项目主题是个人原创内容的沉淀与阅读，不做泛社交信息流。首批内容围绕本人在 Web 前端课程中的学习笔记、页面实现复盘、工具使用记录和校园生活随记展开；文章的标签、摘要、封面和发布时间共同帮助读者按主题发现内容。内容坚持健康、真实和可阅读，页面设计、交互与数据结构均服务于“写一篇、找一篇、读完一篇”的流程。

## 用户与数据

目标用户包括两类：

- 作者：我本人，使用平台撰写草稿、编辑文章、设定分类和标签、发布文章，并查看自己的文章统计；
- 访客：同学或朋友，在本机演示时以访客身份阅读文章、搜索内容、点赞、收藏或评论。

基础版的数据来自本人已有及后续持续撰写的真实课程笔记、项目复盘和生活记录；图片由本人截图或拍摄，避免从不明来源搬运。数据至少包含五类字段：用户资料（昵称、头像、角色）、文章（标题、正文、摘要、封面、发布时间、草稿状态）、分类与标签、评论（内容、作者、时间）和互动记录（点赞、收藏）。数据以 JSON 结构保存在浏览器 `localStorage` 中，并预留导入、导出能力，方便备份真实内容。

## 功能与版本

### 单机版本（必做）

- 本地登录：提供作者与访客身份；不同身份显示不同操作入口，访客不能编辑作者文章；
- 文章管理：新建、编辑、删除、保存草稿和发布文章；正文先采用受限 Markdown 语法或纯文本，避免在编辑器本身投入过多复杂度；
- 阅读与归档：首页文章列表、文章详情、分类页、标签页、按标题和标签搜索、按时间排序；
- 轻量互动：访客可对文章点赞、收藏、发表评论；作者可删除自己文章下的不当评论；
- 个人主页：展示作者资料、已发布文章、分类分布和文章数量；
- 本地持久化：刷新页面后保留登录状态和已录入的内容，并提供数据导出为 JSON 的备份入口。

单机应用通过静态页面直接打开或由本地开发服务器运行，核心数据仅保存在当前浏览器中；演示用访客账号和作者账号不代表真实网络账号。

### 网络版本（可选升级）

将数据访问层替换为 RESTful API 或 Supabase，使真实用户可注册、跨设备保存文章并阅读其他作者内容。多人评论、公开作者主页和内容共享属于网络版本，基础版不承诺实时消息、私信、推荐算法或复杂审核后台。

## 技术选型

采用 HTML、CSS 和原生 JavaScript 实现，不使用 Vue、React 等框架。HTML 负责语义化结构和表单；CSS 使用 Flexbox、Grid、媒体查询与 CSS 变量完成响应式阅读布局；JavaScript 负责 DOM 渲染、路由状态、表单校验、搜索筛选、交互事件和数据转换。

数据访问统一封装在独立的 `data` 模块中，页面组件不直接读取或写入 `localStorage`；初期由该模块管理本地 JSON 数据，后续网络版仅替换该模块的实现。图表若实现，优先用原生 SVG 或 Canvas 展示文章数量和分类分布，不额外引入图表框架。

## 里程碑

| 时间节点 | 可运行增量与检查内容 |
| --- | --- |
| 第 2 周 | 完成立项、信息架构和低保真页面草图；建立仓库与静态首页，可展示真实文章样例。 |
| 第 4 周 | 完成响应式首页、文章详情、分类标签和本地文章列表读取；可浏览、搜索和筛选文章。 |
| 第 6 周 | 完成登录状态、作者文章新建/编辑/草稿/发布及 `localStorage` 持久化；可独立完成一次写作流程。 |
| 第 8 周 | 完成评论、点赞、收藏、个人主页与权限差异；进行手机与桌面端适配。 |
| 第 10 周 | 完成数据导入导出、异常提示、可访问性基础检查和项目演示内容整理。 |
| 后续可选 | 在不影响单机版的前提下，将独立数据访问层接入后端或 Supabase。 |

## 风险与对策

1. **真实文章数量不足**：先以本人已有课程笔记和页面复盘为首批内容，每周至少整理一篇；若数量仍少，保留完整的创作、归档和检索流程，不以虚构大量文章充数。
2. **富文本编辑器开发成本过高**：基础版使用受限 Markdown 或纯文本编辑、预览分离；复杂所见即所得编辑器不纳入必做范围。
3. **功能膨胀为社交平台**：以“个人创作与阅读”为边界，优先保证文章管理、检索归档和本地持久化；私信、关注、实时通知、推荐算法和多人协作全部后置。
4. **本地数据被浏览器清理或无法迁移**：实现 JSON 导出与导入，演示前导出备份；网络存储仅作为后续升级方案。
5. **后续接入后端时重写页面**：从第一版开始由独立数据访问模块承担存取，页面只调用其接口，避免在页面逻辑中散落 `localStorage` 操作。

## 自由补充：核心数据示例

```json
{
  "article": {
    "id": "article-001",
    "title": "用 Grid 完成课程作品首页布局的复盘",
    "summary": "记录页面分栏、断点和布局问题的解决过程。",
    "content": "...",
    "category": "前端学习",
    "tags": ["CSS", "Grid", "课程复盘"],
    "cover": "images/grid-layout.png",
    "status": "published",
    "publishedAt": "2026-09-19"
  }
}
```

该结构与用户、评论、收藏等记录通过 `id` 关联，基础版在本机完成全部读写；若进入网络版本，保留相同业务字段并由后端数据源替代本地存储。
